# GuideGlass AI 👓
### محيط أوضح، استقلالية أكبر.
نظارة مساعدة للمكفوفين وضعاف البصر، هدفها تسهيل فهم المحيط والتنبيه إلى العوائق القريبة صوتيًا.

**👓 نظارة قابلة للارتداء · 📷 كاميرا للمحيط · 📡 ألتراسونك لقياس المسافة**

الكاميرا تنقل الصورة إلى برنامج Windows، وحساس الألتراسونك يرسل المسافة؛ تُعرض النتائج في المتصفح وتُستخدم القراءة الصالحة لإطلاق تنبيه صوتي عربي.

**دليل التشغيل:** [نتائج فعلية قابلة للفحص](docs/evidence/README.md) — كاميرا متصلة وصور مستقبلة؛ ربط الألتراسونك وقراءته الميدانية ما زالا بحاجة إلى تحقق.

**تشغيل:** Python 3.12 → `setup_windows.bat` → `start_windows.bat` → افتح `http://localhost:8766`، وأدخل عنوان وحدة الكاميرا والحساس.

**الحالة:** نموذج أولي للمساعدة اليومية؛ يكمّل العصا البيضاء ولا يُعتمد عليه وحده للملاحة أو عبور الشوارع.
